## How to swap a screenshot

1. Capture / export a screenshot of the app.
2. Name it and drop it in THIS folder, e.g. `mcp-server.png`
3. In `index.html`, find the matching line and swap the file name:
   `assets/projects/mcp-server.svg`  ->  `assets/projects/mcp-server.png`
4. Save. Done.

## Tips

- Keep each image under ~300 KB (resize or compress before uploading)
  so the page loads fast.
- Crop to the interesting part of the app (no taskbar, no window borders).
- A short looping GIF (a few seconds, small area) also works if you want
  to show interaction.
